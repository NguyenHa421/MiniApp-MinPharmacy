# Project Rules

## Tech Stack
- React
- TypeScript
- Zalo Mini App
- Tailwind CSS

## Architecture
- Components chỉ nhận props.
- Không hardcode dữ liệu trong component.
- Dữ liệu đi qua Service -> Hook -> Component.
- Chuẩn bị để sau này dùng WooCommerce REST API.

## Coding Rules
- Không sửa nhiều hơn một feature trong một lần.
- Giải thích thay đổi trước khi sửa.
- Hỏi ý kiến trước khi tạo hoặc xóa file.
- Ưu tiên tái sử dụng component.
- Không thay đổi giao diện nếu không được yêu cầu.
